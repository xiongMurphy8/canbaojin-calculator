# 广东企业残保金测算工具

一个面向广东企业 HR、财务及经营者的静态测算页面，用于快速了解：

- 企业当前预计需要缴纳多少残疾人就业保障金
- 达到规定安置比例大约需要新增多少名残疾职工
- 扣除工资、企业承担社保公积金等用工成本后的合作毛收益
- 再扣除合作服务费后的企业最终净收益

## 在线使用

- 腾讯云正式地址：https://canbaojin-d7gfb2yfg490fc759-1427274058.tcloudbaseapp.com
- GitHub Pages：https://xiongmurphy8.github.io/canbaojin-calculator/

无需安装软件或注册账号。腾讯云正式地址支持用户主动同意后保存测算记录；GitHub Pages 受免费套餐安全域名限制，仅提供测算功能。

云端记录使用 CloudBase PostgreSQL，并通过 RLS 将每条记录绑定到匿名用户身份。数据库结构与权限配置保存在 `cloudbase-postgresql.sql`，前端不包含管理员 API Key。

## 后台管理

页面里新增了“后台管理”页签，用于查看、筛选和导出记录。它通过一个安全的后台接口读取数据，不把数据库管理员密钥写死在前端。后台接口尚未部署时，页面会保留配置入口，但不会直接读取数据库。

后台接口建议返回以下任一格式：

- `[{...record}, {...record}]`
- `{ "records": [{...record}, {...record}] }`
- `{ "data": [{...record}, {...record}] }`

每条记录至少建议包含：

- `id`
- `created_at`
- `company_name`
- `contact`
- `inputs.city`
- `inputs.district`
- `inputs.staff_count`
- `results.client_net`
- `results.fund_saving`
- `results.service_fee`
- `policy_status`

前端会自动做关键字、城市、日期范围和最低净收益筛选，并支持导出当前筛选结果为 CSV。

如果你后面要把后台接口接到腾讯云函数，优先采用“HTTP 云函数 + Bearer Token”方式，避免在网页里暴露数据库管理员权限。

## 使用说明

优先准备上年平均在职人数、上年度工资总额和现有已认定残疾职工年平均人数。页面只支持真实就业场景测算，不支持挂证不上岗、倒填入职月份或补造考勤、工资及社保记录。

## 重要提示

页面中的地区政策参数、工资上限及优惠口径可能随年度调整。历史参考值只用于初步试算，正式申报前应通过主管税务机关、残联、电子税务局或最新官方通告复核。

本测算仅供经营决策参考，不构成税务、法律或政府审批结论，最终以企业实际情况及主管部门审核口径为准。

测算记录不会自动上传，只有用户展开保存表单、勾选同意并点击“确认并保存”后才会提交。系统不收集残疾员工姓名、身份证号或残疾证号。
