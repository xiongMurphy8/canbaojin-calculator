# 广东企业残保金测算工具

一个面向广东企业 HR、财务及经营者的静态测算页面，用于快速了解：

- 企业当前预计需要缴纳多少残疾人就业保障金
- 达到规定安置比例大约需要新增多少名残疾职工
- 扣除工资、企业承担社保公积金等用工成本后的合作毛收益
- 再扣除合作服务费后的企业最终净收益

## 使用说明

优先准备上年平均在职人数、上年度工资总额和现有已认定残疾职工年平均人数。页面只支持真实就业场景测算，不支持挂证不上岗、倒填入职月份或补造考勤、工资及社保记录。

## 重要提示

页面中的地区政策参数、工资上限及优惠口径可能随年度调整。历史参考值只用于初步试算，正式申报前应通过主管税务机关、残联、电子税务局或最新官方通告复核。

本测算仅供经营决策参考，不构成税务、法律或政府审批结论，最终以企业实际情况及主管部门审核口径为准。

测算记录不会自动上传，只有用户展开保存表单、勾选同意并点击“确认并保存”后才会提交。系统不收集残疾员工姓名、身份证号或残疾证号。
